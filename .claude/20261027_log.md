`input_manifest()` read package versions with `importlib.metadata` of the interpreter running the script, which is the
system Python (no torch), so `PackageNotFoundError: torch`.

Before:
```python
    versions = {p: importlib.metadata.version(p) for p in VERSION_PACKAGES}
    return dict(files=table, versions=versions, python=f'{sys.version_info.major}.{sys.version_info.minor}')
```
After:
```python
    return dict(files=table, **env_versions())
```

Why: N1 compares the node's env with the local env, so the versions and Python must be the env's own (torch
2.11.0+cu130, Python 3.11), not the system Python's. The rerun wrote the manifest (71 files hashed).
