# /src/model/combiner.py (follow-up)

Before:
```python
gamma, beta = self.conditioner(label_features).chunk(2, dim=-1)
```

After:
```python
gamma_raw, beta = self.conditioner(label_features).chunk(2, dim=-1)
gamma = self.gamma_scale * torch.tanh(gamma_raw)
```

`CombinerFiLMResidual`'s gamma was unbounded, so the multiplicative gate could grow arbitrarily during training and destabilize the frozen CLIP geometry the design is meant to protect — the initial implementation missed the report's bounded-tanh recommendation for candidate 2. Bounded gamma to `gamma_scale * tanh(...)` (default `gamma_scale=0.1`, a new constructor arg), applied after the existing zero-initialized projection so `gamma=0` at init is preserved exactly (`tanh(0)=0`). Beta stays unbounded (additive, lower risk). Re-ran `src/test/20260902_combiner_architecture/test_identity_init.py` — still passes.
