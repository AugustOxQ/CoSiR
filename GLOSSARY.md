# CoSiR glossary

The project's terms, written by the grill (research loop step 5) and used by briefs and reports. Created 2026-10-09 for round 6.

| Term | Meaning |
|---|---|
| PercepT, core reimplementation (code tag `percept_core`) | our PercepT code with the four result-changing fixes of the [code audit](docs/reports/auto/percept/2026-12-04_percept_code_audit.md) (image-caption pairs, the paper's Eq. 2 fusion, its topic-count algorithm, multi-hot Stage 2 targets), on our own features; the PercepT row of the main tables on our protocol (user, 2026-10-17) |
| PercepT, faithful reimplementation (code tag `percept_faithful`) | PercepT with all eight audit changes and its own encoders (CLIP L/14, ModernBERT tuned on GoEmotions); needed before submission, run on our protocol and in the paper's own setting to show it reproduces the paper's numbers (user, 2026-10-17) |
| PercepT, paper settings, strict (code tag `percept_paper_strict`) | PercepT core's arms P1 (CLIP + RoBERTa) and P4 (Qwen Stage 1, CLIP patches) with the paper's training settings (the third 500-wide autoencoder layer, latent noise 0.1, batch 512, cosine learning rate to 1e-5, no balance term, at most 200 joint epochs; Stage 2 batch 64, lr 1e-3, cosine) and the paper's Algorithm 1 topic cut (γ = 2); only the backbone differs from the paper. "Collapsed" when it keeps under 10 or over 90 topics, or one topic holds over half the fit pairs; a collapsed run leaves the bar (user, 2026-10-20) |
| PercepT, paper settings, K = 40 (code tag `percept_paper_k40`) | as the strict version, but keeps the 40 of 100 topics with the most fit pairs (PercepT core's A3) instead of Algorithm 1; "collapsed" only by the one-topic rule (user, 2026-10-20) |
| recipe | the student's training loss: which terms it keeps (buddy terms on the instructed graphs, own-caption terms, the teacher term toward the instructed Qwen image) and their weights; since report 12-24 the recipe is the one without own-caption terms at teacher share 1/5 (code name R6-5) (user, 2026-10-25) |
| teacher share | the teacher term's weight divided by the sum of all term weights, where the buddy terms count 1 and the own-caption terms 1; a nominal share, not the measured share of the loss value; 1/5 for D2 (0.5 of 2.5) and for the current recipe (0.25 of 1.25) (user, 2026-10-25) |
| matched arm | an encoder's own PercepT arm: PercepT core (P3, 40 topics) with the claim test's Qwen Stage 1 topics and its Stage 2 trained on that encoder's default image; beside the student on the same encoder it drops only the student (user, 2026-10-25) |
| frozen input | an encoder's default image embedding clustered directly, with no training (in tables: the frozen image, F with the encoder's number); the starting level of that encoder (user, 2026-10-25) |
| seed range | the spread (maximum minus minimum) of a score over model seeds, measured on the development (validation) split of the dataset and task at hand; the unit for a "small" effect, for LEVEL and for the guards. Clustering AMI on ArtELingo: D2's AMI over seeds 0, 1 and 2 on the 5,000 old development paintings (report 12-22): emotion 0.0046, style 0.0082, genre 0.0128. Retrieval mAP on ArtELingo: c*'s mAP over seeds 0 to 4 on the validation paintings, plain cosine (report 12-29): emotion 0.0014, style 0.0022, genre 0.0038. Affection's values come from Affection validation in r12 (user, 2026-10-25; widened 2026-10-30) |
| dollar weight | token use priced at API rates (cache reads, cache writes and output weighted by their price) to compare runs of agent work; not what the Max plan charges ([engine switch check](docs/reports/auto/process/2026-11-26_engine_switch_check.md)) |
| relational term | a loss on the genre head that makes each painting's pattern of similarities to other paintings copy the teacher's pattern (the teacher: the instructed Qwen genre image); the field's name is relational (similarity-distribution) distillation ([literature note 12-26](docs/reports/literature/2026-12-26_relational_genre_term.md)); it sits beside the teacher term, which the code calls the direct term; it compares against the other paintings of the batch unless it uses teacher anchors (user, 2026-10-26) |
| teacher anchors | a fixed set of teacher vectors (the instructed genre images of 4,096 training paintings, drawn once per run) that the relational term compares every painting against, in place of the other paintings of the batch; the form of SEED and CompRess (user, 2026-10-26) |
| c* (code name `k11=40`) | the student picked in r10: recipe G with 40 graph neighbours; one shared trunk with emotion, style and genre heads, trained on ArtELingo paintings with Qwen3-VL-Embedding's instructed graphs, captions and teacher, and fed only the default image at test ([report 12-28](docs/reports/auto/percept/2026-12-28_recipe_sweep.md)); the paintings model (user, 2026-11-02) |
| photo model | c*'s emotion pathway (both trunks and the emotion head) fine-tuned on Affection's unlabeled train photos with the settings picked on Affection validation (80 graph neighbours); frozen since [report 2027-01-01](docs/reports/auto/percept/2027-01-01_photo_finetune.md) (user, 2026-11-02) |
| teacher | the Qwen3-VL-Embedding-2B image embedded under one aspect's instruction ("Represent the emotion that this artwork, or this description of an artwork, conveys. Focus only on the emotion."; style and genre alike); the teacher term pulls the student toward it, and it is the student's strongest comparator (user, 2026-11-02) |
| told, untold retrieval | told: the aspect name picks c*'s head, and that head ranks the gallery (r11 to r15's protocol); untold: the query is the image only, c*'s three heads are joined into one vector (each head unit-normalized, 6,144 wide), and one ranking is scored with each aspect's labels, against the plain image (also untold); the terms come from the other authors' feedback (user, 2026-11-03) |
| aspect-switch table | in retrieval, a 3×3 mAP table per model: the rows are the aspect name of the query (which head ranks the gallery), the columns the aspect whose labels decide what counts as a hit; the diagonal is the usual aspect retrieval, the off-diagonal cells show how much the hits follow another aspect; a model that ignores the aspect name (the plain Qwen image) has three equal rows (user, 2026-10-29) |
| TPIPS | an outside method (arXiv 2607.18237, 2026): the Qwen3-VL-Embedding-8B embedder fine-tuned on human odd-one-out votes, which embeds an image under a factor named in text; r18 uses the released 8B late fusion model with the aspect name as the factor (user, 2026-11-03) |
| CLAY | an outside method (CVPR 2026, arXiv 2604.11539): training-free; it projects a frozen CLIP image onto the subspace spanned by text values of a condition (for example 50 or 100 emotion words); r18 runs it on CLIP L/14 (user, 2026-11-03) |
| TURTLE | a label-free clustering method (ICML 2024): it searches for the partition whose linear classifiers separate the classes with the largest margin in a frozen space; needs the cluster count; r18 uses it in place of k-means (user, 2026-11-03) |
| TEMI | a label-free clustering method (BMVC 2023): clustering heads trained on frozen features with a teacher copy and nearest-neighbour pairs; needs the cluster count; r18 runs it after TURTLE (user, 2026-11-03) |

The conditioned line's terms (aspect, episode, reader, AFF, B′ scorers, held read and the rest) are archived: [glossary of the conditioned line](archive/v2_conditioned/GLOSSARY.md).
