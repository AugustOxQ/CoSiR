## Method

Attention-h1 keeps the original content and affect teacher-graph symmetric InfoNCE losses on its L2-normalized fused embedding. A separate Linear-ReLU-Linear cluster head maps that embedding to an unnormalized Euclidean latent. PercepT's unchanged Student-t soft assignments, detached target distribution, and highest-norm-center pruning operate only there. The head's fused-embedding input is detached because the un-detached sibling leaked DEC gradients into the shared student trunk; DEC now updates only the head and centers, while the two InfoNCE losses still update the trunk. There is no embedding noise, discrete reclustering, or Leiden pass.

Each run initializes 100 centers using KMeans(n_init=10, random_state=seed) on its own clean epoch-0 cluster latent, then retains 67 highest-norm trained centers. Vector norm is a meaningful pruning proxy in this unconstrained Euclidean space. The student, head, and centers use one Adam optimizer. LAMBDA_DEC is screened over (0.1, 0.5, 1.0), with a linear 30-epoch warm-up to limit premature self-sharpening. Adam starts at 0.001; cosine T_max=200, eta_min=1e-05; checkpoint cadence=5. The sibling's recall-plateau rule can stop training before warm-up ends. All-100-center sizes use the clean training forward before the optimizer step; checkpoint recalls evaluate the updated student. Both silhouettes use the same hard labels and the same seed-42 two-stage sample: at most 6,000 nodes, then silhouette_score(sample_size=min(4000, n), random_state=42). A score is n/a if the scoring sample has fewer than two labels; cluster-size collapse is diagnosed separately. The fused silhouette is the headline comparable to prior buddy pilots.
