## 1. The paper's design as a checklist

The paper names metrics but does not specify their library implementations, split sizes, sampling, or most averaging conventions (§5.3). Standard metric interpretations below are distinguished from explicit paper instructions.

| ID/component | Paper requirement and all stated settings |
|---|---|
| C1 Datasets | ArtELingo + ArtELingo-28: approximately 1.2M **pairs**, 28 languages, WikiArt images, caption emotion and image genre; translate non-English captions into English with GemmaX2-28-9B-v0.1. Affection: approximately 500K English realistic-image pairs, no genre (§5.1). |
| C2 Encoders | CLIP ViT-L/14, `openai/clip-vit-large-patch14`, image and text each 768-D; ModernBERT-base fine-tuned on GoEmotions, 768-D caption emotion embedding (§4.2; reference identifies `cirimus/modernbert-base-go-emotions`). |
| C3 Clustering unit | One image–caption pair, allowing the same image to occupy several topics through different captions (§3; §4.4). |
| C4 Fusion | `hC=(hT+hI)/2` (Eq. 1); `hC'=hC*||hE||`, affect rescaled by original `||hC||`; `h=(2*hC'+rescaled_hE)/3` (Eq. 2). Alternative: concatenate three vectors and learn a linear projection to 768. Weighted mean performs better (§4.2). |
| C5 Autoencoder | Symmetric MLP, ReLU hidden activations; encoder hidden widths **[500,500,500,2000]**, latent 128; mirrored decoder (Appendix E). |
| C6 Pretraining | Corrupt **latent** with Gaussian noise, SD 0.1; reconstruct clean h; 100 epochs or convergence (§4.1). Appendix E: MSE, Adam lr 1e-3, cosine annealing to 1e-5, batch 512, 100 epochs. Main equation instead writes unsquared L2. |
| C7 Clustering objective | Student-t `qij ∝ (1+||zi−μj||²)^−1`; `fj=Σi qij`, `pij ∝ qij²/fj`; minimize `KL(P||Q)+λR LR`, jointly updating encoder, decoder, centers (§4.1, unnumbered equations). Main λR=1; ablations 0.1, 10, 100 (Table 1). Despite “DEC” naming, reconstruction remains active. Target-update interval unspecified. |
| C8 Joint protocol | Maximum 200 epochs or convergence (§4.1); Adam lr 1e-3, same cosine scheduler, batch 512, 200 epochs (Appendix E). |
| C9 Centers/pruning | k0=100; K-means on pretrained latents (Appendix E). Algorithm 1 sorts norms ascending, finds largest adjacent gap g, and returns its midpoint iff `g > γ*mean(gaps)`; otherwise None. Discard centers **above** threshold (§4.3). γ unspecified; 67 survivors is an example (Fig. 4), not a target. |
| C10 Stage 2 targets | Per-image **multi-hot union**: topic positive iff **any caption** belongs to it; freeze discovered topics (§4.4; Appendix E). “One-hot” wording conflicts with the explicit rule. |
| C11 Multi-head mapper | Learned topic queries; image-token keys/values; inner width `H*dk`, scaled dot products `1/sqrt(dk)`, learned H×H talking-head mixing **before** softmax, attention dropout, concatenation/output projection (Appendix A.1, Eqs. 6–12). H, dk, dropout rate unspecified. |
| C12 Attention pooling | Shared linear scalar attention on tokens; softmax over sequence; weighted sum; linear K-output projection and sigmoid (Appendix A.2, Eqs. 13–16). This is main PercepT (§4.4). |
| C13 Linear mapper | Affine K-output layer plus sigmoid on image **CLS/global vector**, without patches (Appendix A.3, Eq. 17). |
| C14 Mapping training | BCE averaged across K (Eq. 5); frozen topic labels; 100 epochs, batch 64 images, Adam lr 1e-3 and same cosine scheduling (Appendix E). Assignment threshold δ; Appendix B fixes δ=0.5. |
| C15 Internal evaluation | SI, DBI, CHI (§5.3; Tables 1/3). Standard meanings: SI averages `(b−a)/max(a,b)`; DBI averages worst within-scatter/separation ratios; CHI is between/within scatter adjusted by cluster/sample counts. Exact evaluation space, distance, sampling, and train versus held-out computation unspecified. |
| C16 External evaluation | ARI (called “Rand score (ARI)”), AMI, homogeneity, completeness, V-measure (§5.3); FMI additionally appears in Tables 1/3. Standard meanings: adjusted pair agreement; chance-adjusted mutual information; conditional-entropy purity/coverage and their harmonic mean; geometric mean of pair precision/recall. **Report harmonic mean of emotion and genre scores** (§5.4.2). Labels independent of training; exact split unspecified. |
| C17 Mapping evaluation | Multi-label AUC primary; precision, recall, F1, **exact-match** accuracy (§§5.3, 5.5); fixed δ=0.5 for F1 (Appendix B). Macro versus micro averaging and degenerate-label handling unspecified. Unseen-image mapping is intended (§§1, 4.4), but actual evaluation partition is unspecified. |
| C18 Baselines | BERTopic: CLIP B/32 images, default MiniLM text, joint multimodal embeddings, UMAP neighbors 15/components 5/cosine, default HDBSCAN, `nr_topics=100` via reduction (Appendix D). Also CEMTM original training; VLM2VEC v1/v2; K-means on hC or h after PCA/SVD, PCA reported (§5.2). |
| C19 Qualitative/human | t-SNE (§5.3); assignment-probability sampling of pairs and Qwen3-14B producing exactly 10 keywords (Appendix C). Human comparison: keyword-Jaccard cluster matching, randomized/anonymized sides, four annotators, 113 samples (Appendix F). |

## 4. Additions the paper does not have

- **Uniform-marginal balance penalty:** `KL(Uniform || mean(Q))`; initially λ=1, later 1000 (`run_percept_stage1_stabilized_pilot.py:108–116`; `run_percept_stage2_fixed_pilot.py:57,130–136`). Added after unbalanced occupancy deterioration (`percept_stage1_stabilized_pilot_report.md:11,27–39`). H2H searches λ=10–10000 and cannot select zero (`percept_k40.yaml:29–32`; `percept_k16.yaml:29–32`). Fair as a labeled ablation; not a faithful §4.1 baseline.
- **Reconstruction annealing:** λR decays 1→0.1 over 200 epochs (`run_percept_stage1_dec_recon_anneal_pilot.py:57–59`), motivated by a hypothesis that reconstruction opposes separation (`percept_stage1_dec_recon_anneal_pilot_report.md:7`). Legitimate experiment, absent from §4.1.
- **Mapper capacity/weighting/target sweeps:** multiple queries, hidden head, inverse-frequency sample weights (`stage2.py:14–58`), motivated by expanding the fixed pilot (`stage2.py:1–6`); threshold sweep sought nontrivial multi-label targets (`run_percept_topic_qualitative_check.py:37–40`). These alter capacity, objective, or task. Equal search spaces improve comparison fairness but do not establish Appendix A/E fidelity.
- **Forced K and occupancy gates:** fixed low-norm counts were retained because a gap attempt kept 99/100 (`run_percept_stage1_faithful_recipe_fixed_pilot.py:102–118`). Collapse is defined as over half of centers below 1% (`run_percept_stage1_pilot.py:275–277`), absent from §3/§4.3. Uneven occupancy alone is not proof of invalid perception topics.

Would remove **from the faithful configuration**, deleting no artifacts: balance, reconstruction annealing, forced-survivor counts, synthetic target thresholds, extra mapper queries/MLP/weighting, and Pareto gates (locations above).

## 6. Evaluation protocol

**The metric names overlap; the present benchmark is not the paper's evaluated task.**

1. **AMI:** H2H uses sklearn adjusted MI on one topic/majority emotion per painting, genre only where present (`pilot_metrics.py:78–89`; `h2h_store.py:110–120`). Paper uses pair emotion/image genre and harmonic aggregation (§§3, 5.1, 5.4.2). Pair evaluation also weights multiply-captioned images repeatedly. Report individual scores and `2eg/(e+g)` with a declared policy for negative/zero scores; the paper leaves that edge case open.
2. **Assignment protocol:** pilots report train and frozen-centroid held-out results (`run_percept_stage1_pilot.py:402–409`). H2H primary uses cosine-neighbor transfer; independent Leiden measures a new partition, not DEC's discovered topics (`h2h_eval.py:24–50`). Keep native DEC evaluation primary for faithful PercepT; report matched transfer separately. The paper does not identify a Stage 1 train/test protocol (§5.3).
3. **Silhouette:** pilots use Euclidean Z-space distances; anneal uses nested 6000/4000 subsampling (C15). H2H omits it. Paper's 0.97 has unspecified sampling/space (§§5.3–5.4.2); neither a different-space score nor a held-out score establishes reproduction. Add DBI/CHI and distinguish common-input versus method-latent geometry.
4. **Macro ROC AUC:** code computes each valid topic's ROC AUC, then unweighted mean, dropping all-positive/all-negative columns (`stage2.py:65–83`). This is defensible, but macro averaging/skips are unspecified (§5.3). More seriously, H2H primary **and native** AUC use one-hot targets (`h2h_eval.py:54–59`); earlier 0.8290 uses threshold-generated targets (C10). Neither represents the paper's caption union (§4.4). Report label support, skips, P/R/F1 and exact-match accuracy, not AUC alone.
5. **Selection:** H2H has val/test halving (`h2h_split.py:11–28`) and AUC-only selection (`h2h_trial.py:286–292`), rather than older conjunctive gating (`objective.py:17–19`). K acceptance still differs: Buddy allows ±2 (`h2h_trial.py:36,228–230`), PercepT requires exactly K populated train topics (`h2h_trial.py:255–259`); empty train topics are dropped and unmatched held-out assignments redirected (`h2h_percept.py:87–100`). These are harness conventions absent from §4.3. This is cleaner locally, but test paintings informed prior development (matched report :123–129, cited above). Paper split/search details are unspecified (Appendix E/§5.3). AUC across each system's own topics measures different prediction problems; high AUC alone cannot establish superior perceptual coherence (§5.3).

## 7. Verdict and the shortest path to a faithful baseline
