## Data

Frozen sample: /project/CoSiR/src/test/20261017_prompted_aspect_views/sample.npz (np.load, allow_pickle=False).

- Per caption (99,999 rows): sample_ids (int64 extraction id), pid (painting index, 0 to 19,888), painting_ids (name),
  emo (emotion label, -1 means none), sty (style label), gen (genre label).
- Per painting (19,889 rows): first (row index of the painting's first caption), all_painting_ids (name).
- subset_pid (5,000 painting indices): the evaluation paintings. The order of subset_pid is the row order of every
  5,000-row output below.

Labels of the 5,000 evaluation paintings, in subset_pid order:

- emotion: the majority of emo over the painting's captions with emo >= 0 (9 classes, 0 to 8); ties go to the smallest
  class id; -1 when no caption of the painting has emo >= 0.
- style: sty of the painting's first caption (row first[p]).
- genre: gen of the painting's first caption.
- Each label is scored only on paintings with label >= 0.

The clustering score of a 5,000 x d matrix X against a label vector y:

1. X as float32.
2. For r in 0, 1, 2: pred_r = sklearn.cluster.MiniBatchKMeans(n_clusters=20, random_state=r, n_init=3,
   batch_size=4096).fit_predict(X).
3. ami_r = sklearn.metrics.adjusted_mutual_info_score(y[y >= 0], pred_r[y >= 0]), default arguments.
4. score = mean of ami_r over r (also keep the population sd, np.std with ddof=0).

The same three partitions serve all three labels of one matrix.
