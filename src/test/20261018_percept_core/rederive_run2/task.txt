## Data

Frozen sample: /project/CoSiR/src/test/20261017_prompted_aspect_views/sample.npz (np.load, allow_pickle=False).

- Per caption (99,999 rows): sample_ids (int64 extraction id), pid (painting index, 0 to 19,888), painting_ids (name),
  emo (emotion label, -1 means none), sty (style label), gen (genre label).
- Per painting (19,889 rows): first (row index of the painting's first caption), all_painting_ids (name).
- subset_pid (5,000 painting indices): the evaluation paintings. The order of subset_pid is the row order of every
  5,000-row output below.

Labels of the 5,000 evaluation paintings, in subset_pid order:

- emotion: the majority of emo over the painting's captions with emo >= 0 (9 classes, 0 to 8); ties go to the smallest
  class id; -1 when no caption of the painting has emo >= 0.
- style: sty of the painting's first caption (row first[p]).
- genre: gen of the painting's first caption.
- Each label is scored only on paintings with label >= 0.

The clustering score of a 5,000 x d matrix X against a label vector y:

1. X as float32.
2. For r in 0, 1, 2: pred_r = sklearn.cluster.MiniBatchKMeans(n_clusters=20, random_state=r, n_init=3,
   batch_size=4096).fit_predict(X).
3. ami_r = sklearn.metrics.adjusted_mutual_info_score(y[y >= 0], pred_r[y >= 0]), default arguments.
4. score = mean of ami_r over r (also keep the population sd, np.std with ddof=0).

The same three partitions serve all three labels of one matrix.

## The PercepT outputs

Folder: /project/CoSiR/src/test/20261018_percept_core/outputs/stage2/. Read only the *.npz files whose name has the
form <arm>__s<seed>.npz, arm in P1, P2, P3, P4, P5 and seed in 0, 1, 2 (skip any name ending in .pending.npz). Each
holds one array, eval_prob: 5,000 x K float32, the sigmoid output of one trained model for the 5,000 evaluation
paintings, rows in subset_pid order, values in [0, 1]. K differs between files. Some of the 15 files may be absent
(a model that did not train); list each absent one.

For each file:

1. Check the shape (5,000 rows, K >= 2 columns), that every value is finite and in [0, 1].
2. Image-side score: l2-normalize each row of eval_prob (x / max(norm, 1e-12)), then the clustering score above
   against each of the three labels.
3. Argmax score: topic = argmax of eval_prob per row (first maximum on ties); AMI of topic against each label
   (adjusted_mutual_info_score, default arguments, on paintings with label >= 0; no k-means).
4. Record K.

Per arm, over the seeds present: the mean and the population sd (ddof=0) of the image-side score per label, and of
the argmax score per label.

The comparator per aspect (aspect = emotion, style, genre; the label equal to the aspect): among the arms with all
three seeds present, the arm with the highest mean image-side score on that label. If other arms are within 0.003 of
that highest mean (highest minus theirs <= 0.003), the comparator is the one with the lowest arm number among them
(P1 < P2 < ... < P5). Report the comparator arm, its mean and sd, and the highest arm and its mean, per aspect.
