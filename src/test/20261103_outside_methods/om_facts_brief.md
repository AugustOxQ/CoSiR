- Step 2: tokenize the prompt list with max-length padding/truncation; encode text, cast to float, L2-normalize rows; normalize their arithmetic mean to obtain `mu`. Apply spherical `log_map(mu, text)`, subtract the tangent-vector mean, compute SVD, form `P = VT[:r].T @ VT[:r]`. This is a text-derived orthogonal subspace projector, not singular-value reweighting (inferred from the formula). [CLAY main.py:9-25](https://github.com/kaist-ami/CLAY/blob/a3f1890c115ba2caf0221456ae781bcf06a817ab/main.py#L9-L25)
- Step 3: normalize the mean of **database** image embeddings to `img_mu`; normalize `(img_mu + mu)/2` to an intermediate direction. Apply two Householder maps, `img_mu → intermediate → mu`, to both query and database embeddings. [CLAY main.py:62-73](https://github.com/kaist-ami/CLAY/blob/a3f1890c115ba2caf0221456ae781bcf06a817ab/main.py#L62-L73) [CLAY src/utils.py:67-73](https://github.com/kaist-ami/CLAY/blob/a3f1890c115ba2caf0221456ae781bcf06a817ab/src/utils.py#L67-L73)
- Step 4: log-map both aligned image sets at `mu`; multiply by `P` and normalize each projected row. `project_embeddings` returns two **conditioned embedding matrices**, retaining the original feature width; `search` then computes their dot-product matrix and sorts it. The CLI prints mAP and does not save these conditioned matrices. ## D. Retrieval read-out, r11–r15, and CRL precedent

- Task: told-aspect image-to-image retrieval; aspect head/view serves both query and gallery; only labelled rows participate; self excluded, equal aspect label = relevant, singleton-class queries dropped. Full-ranking AP = sum of precision at relevant ranks / number of hits; mAP averages query AP (then model seeds). Stable descending ties preserve gallery row order. Source: `src/test/20261029_retrieval/rt_metrics.py:21-42,75-96`; `src/test/20261102_mmart_test/mt_ret.py:9-12`.
- Read-out menu: W ∈ {none, center, PCA-whiten}; whitening sizes {64,256,1024}, clipped to feature width and deduplicated; each crossed with average query expansion **k ∈ {0,1,3,5,10}**. Each W ends with L2 normalization; R0 = none+k0. 2048-wide heads have 25 read-outs; 50-wide CRL has 15 (inferred from menu). Source: `src/test/20261029_retrieval/rt_readout.py:15-57`.
- Whitening: fit mean/covariance on unlabelled fit rows, covariance denominator n−1, descending eigensystem; transform `(x−mu) @ U_d / sqrt(lambda_d + 1e-6*lambda_max)`. Fit/transform/L2 in float64, output one float32 cast. Source: `src/test/20261029_retrieval/rt_readout.py:62-108`.
- Query expansion: rank original query against gallery, add the top-k gallery vectors to the query, L2-normalize, rerank against the **unchanged** gallery. No class labels choose the neighbours. Similarities/expansion use float64; k=0 disables expansion. Source: `src/test/20261029_retrieval/rt_metrics.py:31-40,84-89`.
- Validation pick: even/odd **positions** of sorted validation paintings form two halves; fit W on one half's images without labels, score the other half, swap, average halves and seeded arms' seeds 0–4. One read-out is picked **per arm jointly across three aspects**, not independently per aspect. Sources: `src/test/20261029_retrieval/rt_readout.py:119-187,209-234`; `src/test/20261029_retrieval/rt_run.py:324-360`.
- For each aspect, `r_a` is c*'s validation max−min mAP over seeds 0–4 at R0. Reject any read-out dropping an aspect below its own R0−r_a; score remaining candidates by `(1/3) sum_a [(mAP_a−mAP_a(R0))/r_a]`. Within 0.001 of best score, tie preference: R0; no expansion; none before center before whiten; smaller k; larger whitening size. Sources: `src/test/20261029_retrieval/rt_stage0.py:68-101`; `src/test/20261029_retrieval/rt_readout.py:44-47,197-234`.
- Held evaluation refits the picked W on **all validation images**, then transforms held images; query expansion occurs on held's labelled gallery with validation-fixed k. There is no held fitting of W. Sources: `src/test/20261029_retrieval/rt_readout.py:111-114`; `src/test/20261030_affection_confirmation/ac_stats.py:209-234`.
- r12 factors selection into `ac_select.arm_table`/`pick_readout`, retains the same menu/cross-fit/guard/tie rule, freezes ArtELingo c* to `center+k10` and CLIP CRL to `none+k10` from r11; it also selects CRL encoder/wording variants and teacher wording on validation.
