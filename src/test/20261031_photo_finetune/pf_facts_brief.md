## 1. Current c*: recipe, training and saved models

- c* is G with only graph neighbours changed to **40**; the selected configuration name is `k11=40`. Full training: **42,969 ArtELingo paintings**, **6,152 validation**, **12,281 held** (genre labels on **9,949** held). Development selection used sample training **13,400 fit + 1,489 stopping**, evaluated on **29,232 development paintings**. [R28:7–13,63–68; RS/rs_full.py:1–16]
- Split construction is image/painting-grouped, seed **42**, with frozen counts and name hashes; validation and held paintings are excluded from fitting. [CT/ct2_data.py:34–38,58–99]
- Student inputs are default Qwen image and default Qwen caption means during training; image and caption sides each have a trunk shared across aspects. Image inference reads only the default image. The image-side architecture is **2048→1024→2048**, GELU, dropout **0.1**, normalized outputs. [CT/ct2_d2.py:283–305; src/test/20261019_model_sheet/ms_train.py:31–45,57–76; RT/rt_stage0.py:202–215]
- Exact emotion instruction: “Represent the emotion that this artwork, or this description of an artwork, conveys. Focus only on the emotion.” Style: “Describe the artistic style of this artwork in one word.” Genre: “Describe the genre of this artwork in one word.” The image teachers use `emotion_focus`, `style_word`, `genre_word`. [src/test/20261017_prompted_aspect_views/pav_prompts.py:4,8,11; RT/rt_data.py:24]
- Graph inputs differ from direct image teachers: **E = instructed emotion caption mean**, **D = default caption mean**, **I = default image**, plus instructed style/genre images. Fit/dev graphs are built separately; edges have unit weights. [CT/ct2_d2.py:283–305; CT/ct2_graphs.py:100–127]
- Graphs: mutual top-**40** cosine neighbours. Emotion `Gres`: standardized E similarity minus per-anchor λ times content; λ is the fraction of E mutual edges shared with the union of D/I mutual edges (zero-degree fallback: mean λ). Content is the mean standardized D/I similarity. Style `Fres05`: standardized style-image similarity minus **0.5×content**. Genre `R0o`: uncorrected instructed genre-image similarity. [RS/rs_graphs.py:81–114; RT/rt_data.py:25]
- Loss per emotion/style head: average of **four** symmetric buddy contrastive terms (image–image, image–caption, caption–image, caption–caption), overall buddy weight **1**, plus **0.25×direct image-teacher cross-entropy**. Own-caption alignment weight **0**; no label classification loss. Genre adds **8×teacher-to-student relational KL**. Buddy/direct/student relational temperature **0.05**; genre teacher temperature **0.02**. [src/test/20261025_recipe_backbones/rb_rows.py:10; src/test/20261021_d2_ablation/ab_train.py:30–49; RG/rg_loss.py:83–128,138–149; RS/rs_sheet.py:11–27]
- Optimizer AdamW, LR **0.001**, weight decay **0.05**, batch **512 graph pairs per active aspect** (twice as many endpoint rows), cap **200 epochs**, patience **15**, independent per-head stopping on minimum validation loss; active aspect losses are summed. Recipe selection instead uses development **k-means AMI**, normalized gains across aspects, not validation loss. [RS/rs_sheet.py:11–27; src/test/20261017_image_transfer_pilot/itp_train.py:15–17; CT/ct2_d2.py:173–232; R28 §Stage 3]
- Selection: sweep seed **0**, confirm seeds **1–3**, choose largest mean gain in aspect seed ranges among eligible candidates (each aspect lower confidence bound >−r, mean-gain lower bound >0). c* mean gain **+0.683 [0.452,0.959]**; full-scale reported model seeds **0–4**. [R28:89–107,138–150]
- Full selected epochs (emotion/style/genre), seeds **0–4**: **4/1/18; 4/3/6; 3/3/2; 3/2/14; 6/1/5**. Trainer seconds per seed: **316.97; 243.47; 212.37; 296.09; 241.31**. These are best checkpoint epochs, not total epochs executed. Sample c* seeds **1–3** took **80.04/77.00/78.29 s**. [RS/20261027_recipe_sweep_log.md:132–151]
- Actual selected model trained locally on **one RTX 3090** (GPU **0**, sequential seeds); sweep stages ran on DAS6 node402 using **three RTX A6000s**, not distributed training of the final c*. [R28:72–81; RS/rs_queue_common.sh:72–75; RS/rs_full.py:295–306; RS/rs_queue_stage4.sh:56]
- Entry point/round: `RS/rs_full.py train --config k11=40 --seeds 0 1 2 3 4 --device cuda --outputs <new-root>`; invoked by `rs_queue_stage4.sh`. Config is Python `rs_sheet.G` overridden with `k11=40`, plus inherited `R6-5` and `GS-0.02` losses; no standalone YAML config. The old round's provenance/pick guards must be satisfied; this is not a ready new-dataset command. [RS/rs_full.py:16,270–294; RS/rs_sheet.py:11,62–69; RS/rs_train.py:5–6]

Emotion-only training can reuse the lower-level `ct2_d2.run(..., aspects=['emotion'])`/`ms_train.build_model()` interface, but current `rg_full.train_cohort()` forces all aspects and the current loader still demands every space. [CT/ct2_d2.py:93–102,128–148,283–305; RG/rg_full.py:224–234; src/test/20261019_model_sheet/ms_train.py:57–76]
- Style/genre **do not need human style/genre training labels**: they need default image/caption inputs, their instructed image teachers, and their respective buddy graphs. Genre also needs the instructed image similarities for KL. Style's content correction needs D/I; the existing complete graph loader additionally requires E. Human labels enter development/held AMI selection/evaluation. [CT/ct2_d2.py:128–148,283–305; RS/rs_graphs.py:89–114; RG/rg_loss.py:88–122; R28 §Stage 3]
- A photo with only an emotion target is **not automatically masked out of other heads**. Current tensors require each selected aspect's teacher on every fit/dev node; graph fit/dev node sets must equal the shared split. An emotion-only cohort is supported, but mixing such rows into an all-head cohort needs changes to eligibility/indexing. Emotion loss would update the shared trunk, so even absent direct style/genre loss, their representations can change. [CT/ct2_d2.py:128–144,173–191; src/test/20261019_model_sheet/ms_train.py:31–45]
- Crucial: c*'s unchanged **emotion graph needs instructed explanation/caption means**, not merely instructed emotion images. Existing Affection default explanations suffice for D and caption endpoints, but do not supply E. Extract E too, or explicitly change the graph recipe. [CT/ct2_d2.py:286–293; CT/ct2_data.py:252–255; A/qwen3vl_emb_2b/index.json:1]
