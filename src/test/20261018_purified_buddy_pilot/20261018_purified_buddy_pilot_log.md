# Purified buddy pilot: controller handoff

2026-10-18, CoSiR. Single-agent build and CPU validation only. The full queue was NOT run. No held/test data, Qwen model, GPU, deletion, commit or .ccg record was used. Writes are confined to this round and the designated smoke folder.

## Question and prespecified bar

Can an image-only student learn emotion from caption-side buddy pairs after removing every emotion edge that also appears in either default caption or default image content graphs? The earlier own-caption InfoNCE pilot failed: default-input students 0.073994 emotion AMI versus control 0.073893, read from ../20261017_image_transfer_pilot/itp_results.json. The current pilot replaces own-caption alignment with image-to-image buddy InfoNCE.

Before graph/training smoke, stated in commentary and printed by the scorer: **S_P emotion AMI >= 0.12 AND mean(S_P) - mean(S_D) > max(sd(S_P), sd(S_D))**. Student sd is population sd over three student seeds; each run's AMI is its mean over the same three k-means seeds. The full research bar is PENDING; no production student runs exist. The one-seed, two-epoch smoke diagnostic is explicitly separate.

## Method and fixed decisions

Only the frozen train-side sample is loaded: 99,999 captions, 19,889 paintings. The upstream fixed evaluation order has 5,000 paintings. itp_data.split supplies 13,400 fit and 1,489 dev paintings; it is never re-derived. Training uses only default Qwen image vectors. Emotion/default caption means are built by imported itp_data.targets; graphs call imported pav_score.mutual_pairs unchanged, separately for fit and dev. E=emotion, D=default captions, I=default images, C=D union I, P=E minus C, N=C minus E. ALL E/C overlap is removed. Fit-only statistics use exactly pav emotion-majority/first-genre/first-style conventions, including negative-label exclusion. Labels never enter graph construction, training, dev loss, stopping, identity or settings.

The imported MLP is Linear(2048,1024), GELU, dropout .1, Linear(1024,2048), then L2 output. AdamW lr .001, weight decay .05; temperature .05; 512 pairs per batch, up to 200 epochs, patience 15. One epoch is exactly one seeded shuffled pass through every positive fit edge. Diagonal targets and symmetric CE implement the two pair directions. Dev uses all pairs, eval mode, fixed sorted order and fixed 512-pair batch boundaries, with pair-count-weighted batch loss. A requested dev graph with fewer than 200 pairs stops before training. The lowest dev-loss state remains in memory and produces the 5,000-row evaluation array.

S_PN draws up to four distinct N-neighbours without replacement for each endpoint anchor and each direction; they come from the same fit/dev painting set. Only valid negative embeddings are evaluated, with gradients; their four per-row logits append after the B in-batch columns. Absent entries are masked to -infinity, including every extra column for anchors with no N-neighbour. Training sampling and shuffled pair order use seeded separate RNGs; torch and numpy are seeded. Dev negative draws restart from the run seed each epoch so early stopping compares the same sampled negatives. This fixes the unspecified dev-negative resampling choice without label access or tuning.

Resume requires exact config, graph/sample identity, graph archive checksums, output hash, shape (5000,2048), float16, finiteness and unit norms (tolerance .01). Current image input hashes must match the fit/dev image graph sources. Existing incompatible sealed outputs raise; incomplete outputs may be recomputed in place, with nothing deleted. An output NPY is the completion marker. Per-run JSON includes graph pair counts, epoch history/times, best epoch/dev loss, epochs, steps and total seconds.

Scoring retains all 5,000 evaluation paintings even in smoke: three unchanged MiniBatchKMeans seeds at k=20, the unchanged five-fold GroupKFold emotion probe, and exact top-20 overlaps to emo and dcap targets. Reference scores are read, never re-run. Full student results use all three seeds. Effects show both student-seed sds; genre/style changes use the imported default_image row. Missing outputs are reported; incomplete groups cannot decide the bar. Original logistic-regression convergence warnings remain in smoke logs; C=.1 and max_iter=300 are unchanged.
