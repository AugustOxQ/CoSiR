## The rule (what to compute)
Spec: /project/CoSiR/docs/superpowers/specs/2026-11-12-siglip-only-adapter-design.md, §3.2 (arms K1, K2, P1), §3.4 first
two bullets and "P1's caption form (D20)", §6 row SC1, §4 rows D5, D11, D20. The text cells follow r23's protocol:
/project/CoSiR/docs/superpowers/specs/2026-11-06-text-claim-design.md §3.3 (labels) and §3.4 ("Cells", "Read-out menu"),
which cite r22's label mAP metric (find r22's spec under /project/CoSiR/docs/superpowers/specs/ if needed).

In short:
1. Arms. K1 = caption tower reads SigLIP 1 caption text rows from /data/SSD2/pre_extract/artelingo_full/siglip_so400m/
   (text side). K2 = the same from /data/SSD2/pre_extract/artelingo_full/siglip_so400m_capprefix/ (prefixed captions).
   Both: image tower reads the SigLIP 1 image rows (siglip_so400m, image side). Weights, seed 0, one checkpoint per
   aspect head: /data/SSD2/cosir_r29/20261112_siglip_only/cstar/siglip1/weights/siglip1/<aspect>__s0.pt (K1) and
   .../weights/siglip1_prefix/<aspect>__s0.pt (K2), aspects emotion, style, genre. A text query is one caption's stored
   row, L2-normalised, through that aspect's caption tower; an image is its stored row through that aspect's image tower.
   Joins by sample ID, with the painting checked (the project's rule: never range(n) or a dataset's own image_id).
2. Set: ArtELingo validation of the painting-grouped split (6,152 paintings, 30,872 captions).
3. Read-out r0 only: raw cosine between the L2-normalised tower outputs (no centering, no expansion).
4. Nine cells per arm: aspect (emotion, style, genre) x direction (t2i, i2t, t2t). Each cell is the label mAP of r22 /
   r23: per-query AP with relevance by the aspect label (a caption's own emotion; a painting's plurality emotion; style
   and genre of the painting; unlabelled rows leave query and gallery, masked only at AP), a query's own row leaves the
   gallery; the cell value is the mean AP over queries with a finite AP (float64 mean).
5. Text group of an arm = the mean of its nine cells. SC1: the arm with the higher text group is K*; an exact tie goes
   to K1 (siglip1).
6. P1 (plain SigLIP 1, no training): the same nine cells and group at r0, with the stored SigLIP 1 rows themselves as
   the vectors (L2-normalised): text rows from the plain store (form "plain") and from the prefixed store (form
   "prefixed"), image rows from the SigLIP 1 image store. P1's form = the form with the higher P1 text group; an exact
   tie goes to plain. (The rule uses P1's form only when K2 wins; compute both anyway.)
