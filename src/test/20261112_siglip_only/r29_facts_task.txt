## Context

The project trains an "aspect adapter": two small towers (an image tower and a caption tower), each a shared trunk plus one head per aspect (emotion, style, genre), trained with a graph-positive contrastive loss on neighbour graphs built from Qwen3-VL-Embedding instructed embeddings. The current main model ("c*" on SigLIP 1) reads the SigLIP 1 image embedding in the image tower and the Qwen3 plain caption embedding (2048 wide, mean over a painting's captions) in the caption tower. The planned next model ("SigLIP-only") keeps every Qwen3 part of training (graphs, content correction, alignment targets) but feeds the caption tower the SigLIP 1 text embedding of the captions (1152 wide) instead of the Qwen3 one, so no input passes through Qwen3 at test time.
