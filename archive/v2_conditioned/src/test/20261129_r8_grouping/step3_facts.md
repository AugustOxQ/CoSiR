## 3. How a grouping plugs in (R7 code, `r7_*.py`)
- Grouping file: `RES/groupings/r7_groupings.npz` (+ .json; N in `r7_grouping_N.npz`): key = ID, int64 local labels over the 183,694 scorer-train rows, compact classes 0..k-1, constant within painting, each group in the head's 60,000-row draw (`r7_heads.py` `load_groupings`, `_labels`; L10). Needs `scorer_train` and `g_st` keys for alignment. IDs are whitelisted in `r7_bundle.py` `load_posteriors` (R0, T, N, V1-6, Z1-6) and `r7_reader.py` GROUPINGS: a new ID needs a code edit.
- Heads (L10): `RES/heads/head_X.{json,pkl}`, `post_X.npz` (keys img, txt, rows; global-row float32, NaN outside the selection rows, rows == ctx.selection; `_posterior_ok`), `xheads_X.npz` (cross-fitted on the two round-1 painting halves: img, txt, filled_by_half, classes_half0/1; rows = scorer-train; each posterior row sums to 1). Head recipe = `r6_heads.fit_one_head_r6`, logistic regression C=1, 60,000 train rows, 10,000 check rows (`r7_heads.py` l.21).
- Reader (L11): `RES/readers/bank_X_half{0,1}.npz`, `reader_X.{npz,pkl,json}`; banks 16,384 episodes per block (98,304 per half), bank seeds 11700/11800, 24 features, built from the xheads (`r7_reader.py` l.1-31, `load_crossfit`). The new grouping sits in the csd slot, class order (affect, image, caption, X).
- Steps: groupings (CPU) -> heads -> readers -> thresholds tau^X (L12) -> scoring (`run_r7.py`: prep, ceiling, gate).
- Own-posterior in place of a CLIP image head: `r7_fusion.py` `told(bundle, parts, told_map, posteriors_override=None)` (l.168-188) accepts a partial `{grouping: {img, txt}}` of global-row float32 posteriors with the standard head's shape, but only on the told route (used for T*, `run_r7_descriptive.py` l.285). `bundle.post` is a dict name -> {img, txt}; each entry is built by `r7_bundle.load_posteriors` from `heads/post_{name}.npz` (r7_bundle.py l.160, `post[name] = load_posteriors(...)`), and the same file is read by the R1/X-AFF scorers and `condition_free`. So a posterior from any source works if it is written in that file format (img and txt, shape n_global x k, NaN outside selection, float32); the reader training uses `xheads_X.npz` in the cross-fitted format (an image-side cross-fit with a new source is not provided in the code). Whether caption-side (txt) posteriors from a CLIP text head must stay: both keys required by `_posterior_ok`.
